# app-remover

Built with the Spec-Driven Development (SDD) pipeline.
Configured for: **node**

## Quickstart
1. `make setup` — install/sync backend dependencies
2. Edit `raw_idea.txt` with your product idea
3. `make all` — run the pipeline: domain → requirements → spec → review → code
4. `make test` — run the test suite

> The pipeline stages (domain … code) need the `claude` (Claude Code) CLI.
> Run `make help` to list all targets.
